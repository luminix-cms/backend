# Reducible Elements

Luminix utilizes the [Reducible](https://github.com/AranduTech/php-reducible.git) package to allow customizations to the package's behavior. This document outlines the available reducers and how to use them.

## Available Reducers

### `ModelFinder::models()`

This reducer is intended for package developers who wants to add their models to API endpoint generation. By default, Luminix will search for models in the `app/Models` directory. To customize this behavior, you can register a custom reducer to return the models you want to use.

```php
use Luminix\Backend\Services\ModelFinder;

public function boot()
{
    ModelFinder::reducer('models', function ($models) {
        return array_merge($models, [
            \Vendor\Package\Models\CustomModel::class,
        ]);
    });
}
```

### `RouteGenerator::modelRoutes()`

This reducer modifies the route array generated by Luminix. You can use this reducer to add custom routes common to all models.

```php
use Luminix\Backend\Services\RouteGenerator;

public function boot()
{
    RouteGenerator::reducer('modelRoutes', function ($routes, $slug) {
        return array_merge($routes, [
            'custom' => [
                'method' => 'post',
                // users/custom, to-dos/custom, etc.
                'path' => "{$slug}/custom",
            ],
        ]);
    })
}
```

### `RouteGenerator::model{$Model}Routes()`

This reducer is similar to the previous one, but it allows you to add custom routes to a specific model.

```php
use Luminix\Backend\Services\RouteGenerator;

public function boot()
{
    RouteGenerator::reducer('modelUserRoutes', function ($routes) {
        return array_merge($routes, [
            'custom' => [
                'method' => 'post',
                'path' => 'users/custom',
            ],
        ]);
    })
}
```
